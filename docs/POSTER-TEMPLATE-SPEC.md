# 海报模板规格（POSTER-TEMPLATE-SPEC）

> 版本：v1.0 | 日期：2026-09-22
> 性质：海报模板 `svg_spec` 的**变量字典、版式坐标规范与文案库事实源**；与种子 `sql/05_poster_template_seed.sql` 逐字对应。
> 输入素材：三张真实营销海报（`资料/` 下渗漏/浴改淋/刷新 jpg）。
> 方案边界（ADR-006）：**模板套版 + 变量填充 + Sharp 合成**，非生成式出图；生成式只允许产出经人工审核的背景素材池，不入跑批链路。
> 阅读对象：后端渲染（实现合成）、设计师（维护版式与素材）、运营（维护文案变量与活动话术）。

## 1. 三张海报的统一版式（反解结论）

三张产品海报虽主题不同，但属于**同一套版**，自上而下九层结构完全一致。这是套版方案成立的事实基础：

| 层 | 名称 | 内容 | 是否变量 |
|----|------|------|----------|
| L1 | 品牌区 | 左上角研选家 LOGO | 固定素材 |
| L2 | 痛点蓝条 | 顶部蓝色刷痕笔触条 + 白色痛点文案（如「卫生间防水，别等渗水发霉再补救」） | **动态文案**（标签词库） |
| L3 | 主标题 | 左对齐大字粗标题，含一个红色/深色强调词组（如「早漏了一年」「立省1㎡」「焕新一整家」） | 模板文案 |
| L4 | IP 人物 | 卡通工人工程师形象（竖拇指/施工姿态），位于标题右侧/压角 | 固定素材（可按包换姿态） |
| L5 | 对比卡 | 左右双卡：左「你看到的/现状」（2~3 个短标签）→ 右「实际原因/同一空间」（一句话结论） | 模板文案 |
| L6 | 材料桶 | 材料品牌+产品名（渗漏=东方雨虹200；浴改淋=壁龛浴室柜；刷新=PPG大师漆） | 模板文案 |
| L7 | 卖点条 | 三枚图标 + 短卖点（横向等距，Lucide 图标线性风格） | 模板文案 |
| L8 | 信任条 | 自营背书横条（如「万科物业自营，不达标砸了重来」） | 模板文案 |
| L9 | CTA 底部 | 左下小程序码 + 扫码主文案 + 副文案（名额/福利）+ 社会证明（「已有 N 户邻居」） | **部分动态**（真实户数、活动名额） |

## 2. 画布与安全区

| 项 | 值 | 说明 |
|----|----|------|
| 画布 | 750 × 1600 px | 竖版 15:32，适配企微/短信落地页主流手机屏 |
| 出血 | 0（数字海报无印刷出血） | 背景图需自行画满 |
| 安全区 | 左右各 48 px、顶部 40 px、底部 48 px | 文字与二维码不得入安全区外 |
| 输出 | JPEG（quality 88，默认，体积小）/ PNG（需要透明或文字极致锐利时） | 单张目标 ≤ 350 KB |
| 色彩 | sRGB；颜色一律引用 Design Token（主色墨钢蓝 `#1D5A96`，强调红取自 Token 语义色），**禁止硬编码色值在渲染代码中** | 对齐 UIUX 视觉门禁 |
| 字体 | 公司品牌授权字体随镜像分发；`loadSystemFonts:false` 显式指定 | 多环境渲染一致，禁止运行时联网拉字体 |

## 3. `svg_spec` 变量字典

种子中三套模板共用同构 `slots`，**槽位键名冻结**（新增只许追加、不许改名）。

| 槽位键 | 类型 | 必填 | 来源 | 渲染规则 |
|--------|------|------|------|----------|
| `brand_logo.asset` | string(OSS key) | 是 | 固定 | 三模板共用 |
| `pain_strip_text` | string | 是 | **动态：规则命中标签 → 痛点词库**（§5.2） | 单行，≤ 18 个汉字，超长缩字号（下限 28px）仍超则截断省略号并记日志 |
| `headline_prefix` | string | 是 | 模板文案 | 主标题深色部分 |
| `headline_highlight` | string | 是 | 模板文案 | 强调色部分，字号同主标题、换强调色；≤ 8 字 |
| `headline_suffix` | string | 否 | 模板文案 | 可空串 |
| `compare_left_title` | string | 是 | 模板文案 | 如「你看到的」「现状：」 |
| `compare_left_items` | string[] | 是 | 模板文案 | 2~3 个，每个 ≤ 6 字 |
| `compare_right_title` | string | 是 | 模板文案 | 如「实际原因」「同一空间」 |
| `compare_right_text` | string | 是 | 模板文案 | ≤ 10 字 |
| `material_brand` | string | 否 | 模板文案 | 浴改淋为空串时不渲染品牌行 |
| `material_product` | string | 是 | 模板文案 | 材料/核心卖点一句 |
| `features[]` | array(3) | 是 | 模板文案 | 固定 **3 枚**；`icon` 取 Lucide 图标名（渲染前校验图标存在），`text` ≤ 6 字 |
| `trust_text` | string | 是 | 模板文案 | 自营背书，≤ 16 字 |
| `cta_title` | string | 是 | 模板文案 | 扫码主文案，≤ 12 字 |
| `cta_sub` | string | 否 | **活动变量** | 名额/福利话术；受 §6.2 活动有效期约束，可空 |
| `social_proof` | string | 否 | **动态：真实项目数据**（§6.1） | 取不到真实数时降级通用话术，禁止编造 |
| `footer_tip` | string | 否 | 模板文案 | 底部警示小字，可空 |
| `qrcode_oss_key` | string | 是 | 固定/按渠道 | 小程序码；一期固定默认码，渠道码为 P1 |
| 坐标类（`x/y/maxWidth/fontSize/color`） | — | — | 版式 | 设计师维护，运营不可见；文字槽位给 `maxWidth` 做自动缩字 |

## 4. 文案库（三套，与 `sql/05` 种子逐字一致）

> 文案库是**冻结基线**：修改已发布模板文案须新建模板版本，不得在旧记录上无痕改写（推送记录要能还原当时海报）。

### 4.1 渗漏检测包（PKG-SEEP）

- 痛点条（动态词库，见 §5.2）：墙根发霉 / 门口发黑 / 地漏反味
- 主标题：你家防水，可能 **早漏了一年**
- 左卡：你看到的「墙根潮湿 / 发黑发霉」→ 右卡：实际原因「防水层已经失效」
- 材料：东方雨虹｜200 柔韧型防水涂料
- 三卖点：`shield-check` 深层渗透修复 / `clock` 快速施工省时 / `badge-check` 防水质保10年
- 信任条：万科物业自营，不达标砸了重来
- CTA：扫码预约免费渗漏检测
- 社会证明：已有100户邻居完成检测（**占位话术，实际渲染见 §6.1**）
- 底部提示：别等渗水发霉再补救

### 4.2 浴改淋包（PKG-TUB2SHOWER）

- 痛点条（动态词库）：浴缸空着 / 收纳不足 / 早高峰抢不停
- 主标题：浴缸秒变淋浴 **立省1㎡**
- 左卡：现状「浴缸常年闲置」→ 右卡：同一空间「淋浴干湿分离」
- 材料：（无品牌行）壁龛浴室柜补收纳，空间利用翻倍
- 三卖点：`shield` 万科物业自营 / `calendar-clock` 超期按天赔付 / `package-x` 不搬家施工
- 信任条：小改造，大改变
- CTA：点击扫码看同户型方案
- 社会证明：20户邻居已改好，你还在等什么？（**同上，真实户数替换**）

### 4.3 墙面刷新包（PKG-REFRESH）

- 痛点条（动态词库）：旧墙掉皮 / 发霉发黑 / 污渍难擦
- 主标题：旧房墙面刷新 **焕新一整家**
- 左卡：现状「霉斑墙面 / 开裂掉皮 / 空鼓脱落」→ 右卡：同一空间「整洁墙面，环保健康、美观耐用」
- 材料：PPG大师漆｜环保等级、遮盖力远超国标
- 三卖点：`shield-check` 万科物业自营有保障 / `hard-hat` 标准化施工自有工人 / `leaf` 精选环保漆安心入住
- 信任条：精细保护 · 腻子精修 · 净味涂料，根源阻断霉斑
- CTA：扫码送3㎡免费刷新
- CTA 副文案：仅限5席，先到先得（**名额活动，受 §6.2 约束**）
- 社会证明：墙面霉斑开裂不用忍，免费墙面勘测+配色方案

## 5. 动态变量规则

### 5.1 家庭/项目变量（来自 `house_label_snapshot`）

| 变量 | 用途 | 规则 |
|------|------|------|
| 家庭结构 | 痛点条候选倾向 | 存储值带 `A_三代同堂` 前缀，**展示必须去前缀**（如「三代同堂」）；本期痛点词库不直接拼家庭名，仅作后续个性化储备 |
| `community_name` | 社会证明/同户型话术的项目维度计数 | 按项目聚合真实户数；为空时降级为城市级或通用话术 |

### 5.2 痛点条生成规则（标签 → 词库，不做自由生成）

痛点条**不允许自由文本生成**（错字与合规风险），只能「命中标签 → 从词库按优先级取一条」：

| 产品包 | 触发标签（contains_any） | 候选痛点文案（按序取第一个命中） |
|--------|--------------------------|----------------------------------|
| PKG-SEEP | `water_tags` | 卫生间漏水→「卫生间防水，别等渗水发霉再补救」；厨房漏水→「厨房门口发黑，可能已经漏到楼下」；阳台漏水→「阳台渗水发霉，快查防水层」；水管老化→「水管老化别硬扛，先做免费检测」；兜底→「墙根发霉 / 门口发黑 / 地漏反味」词库随机（按 house_id 哈希取稳定一条，避免同屋每天变） |
| PKG-TUB2SHOWER | `family_structure` | A/B/C（多成员）→「早高峰抢不停，浴缸该让位了」；D→「浴缸空着还占1㎡」；兜底→「浴缸空着 / 收纳不足」 |
| PKG-REFRESH | `env_tags` | 墙面发霉→「旧墙发霉别再忍，免费配色先看看」；瓷砖开裂空鼓→「墙面开裂空鼓，刷新一步到位」；渗水/返潮→「渗水返潮的墙，刷漆前先断霉根」；兜底→「旧墙掉皮 / 发霉发黑 / 污渍难擦」 |

无任何命中时使用模板默认词库，**不得留空、不得报错阻断**（海报失败不得阻断推送，架构 §7.4）。

### 5.3 同户型方案（浴改淋 CTA）

「扫码看同户型方案」要求小程序落地页能按 `layout`（户型）路由到对应案例；一期若案例库不全，二维码统一落到方案列表页，**海报文案不变但落地页不得 404**（上线前验收项）。

## 6. 合规与真实性红线（比美观更硬）

### 6.1 社会证明数字必须真实（防编造）

- `已有N户邻居完成检测/已改好` 的 N 只允许来自系统计数（检测完成户数 / 改造完成户数，按 `community_id` 聚合）。
- **不足 20 户时不显示具体数字**，降级为固定话术（渗漏：「邻居们都在做免费渗漏检测」；浴改淋：「同小区邻居已经在改造」）。
- 取不到数（接口失败/当日数据未就绪）走降级话术并在渲染日志记 `social_proof_fallback`，**绝不允许用随机数或占位数上画**。

### 6.2 名额/福利话术必须绑定活动有效期

- `仅限5席，先到先得`、`扫码送3㎡免费刷新` 属**承诺型话术**：必须由运营在活动配置中设定有效期与名额；活动结束/名额耗尽当日由运营停用模板或换模板版本。
- 渲染服务在模板带 `cta_sub` 时校验活动状态字段；活动失效则**不渲染该行**（不是渲染过期文案）。
- 固化承诺（免费检测、质保 10 年、超期赔付）以业务合同口径为准，文案修改需业务确认留痕。

### 6.3 视觉门禁（沿用全项目 P0 规则）

- 图标只用 Lucide 线性图标，**禁止 emoji**；禁止紫粉渐变；禁止 Lorem ipsum 与占位文字上画。
- 颜色全部走 Token（墨钢蓝主色 `#1D5A96`），强调色用语义 Token，渲染代码与 svg_spec 中不得出现 Token 外裸色值（白色/黑色文字除外）。
- 二维码最小尺寸 ≥ 160 × 160 px，四周留白 ≥ 16 px；上线前真机扫码验收（iOS/Android 各一）。

## 8. 渲染管线（后端实现要点，对应架构 §7.4）

1. 取模板 `svg_spec` + 变量上下文（命中规则、标签、项目计数、活动状态）。
2. 按 §5 生成动态槽位（痛点条稳定选取、社会证明真实计数与降级、活动行有效性）。
3. 校验：必填槽位非空、features 恰 3 个且图标名合法、文案长度不超限（超限缩字/截断并记日志）。
4. SVG 文本层 → 与背景图用 Sharp composite → JPEG/PNG → 上传 OSS → URL 写 `push_detail.poster_url`。
5. 兜底链：分层背景缺失 → 占位背景+文字渲染并标注；渲染异常 → 纯文本降级消息，**海报失败不阻断推送**；所有降级必须在任务统计中可见。

## 9. 验收清单（模板上线前逐项勾选）

- [ ] 三套模板在 750×1600 下文字无溢出、无错字、无 emoji、无 Token 外色值
- [ ] 痛点条对无标签/单标签/多标签房屋各渲染一次，兜底话术正确且同屋稳定
- [ ] 社会证明：有真实数/不足 20 户/接口失败 三种场景各验证一次，无任何编造数字
- [ ] 名额活动生效期/结束后各验证一次，结束后海报不出现承诺行
- [ ] 家庭结构前缀在所有外露文案中不可见
- [ ] 二维码真机扫码通过，落地页无 404
- [ ] 种子 `sql/05` 的 `svg_spec` 与本文件 §3/§4 逐字一致（机器 diff）
- [ ] 浴改淋规则 disabled 期间，其海报模板仅可预览、不会被任何跑批任务引用
