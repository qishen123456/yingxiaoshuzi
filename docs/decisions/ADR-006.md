# ADR-006: 海报生成采用「模板套版 + 变量填充」而非生成式出图

## Status

Accepted (2026-09-18)

## Background

用户要求「个性化 AI 海报」，但明确「业务可控性与成本优先」的倾向。海报含社区名、主推产品、服务承诺、联系方式等**必须零错字**的信息，且随发送量（日千–万级）放大成本。

候选：

| 候选 | 单张成本 | 单张耗时 | 中文文字准确度 | 品牌可控性 | 运维重量 |
|------|----------|----------|----------------|-----------|----------|
| 模板套版 + 变量填充（后端合成） | 约 0 元 | 20–200 ms | 高（字体渲染） | 高 | 轻 |
| 生成式出图 API（通义万相） | 约 0.2 元/张 | 数秒（异步） | 中（中文易错字） | 低 | 轻（外部依赖） |
| 无头浏览器截图（Puppeteer） | 低 | 300–600 ms，200–400 MB/实例 | 高 | 高 | 重 |

## Decision

选择 **模板套版 + 变量填充，后端使用 Sharp（libvips）合成**。

实现：
- 模板 = 背景图（OSS）+ `svg_spec`（变量占位 `{{community_name}}` / `{{product_name}}` / `{{copy_slogan}}`、坐标、字号、字体、颜色 token 引用）。
- 跑批时按房屋标签 + 产品包填充变量，Sharp 将 SVG 文本层 compositing 到背景图，输出 PNG/JPEG，上传 OSS 得到 `poster_url`。
- 字体随镜像分发、`loadSystemFonts:false` 显式指定，保证多环境渲染一致。
- 渲染失败降级为「默认模板 + 纯文本」，不得阻断整条推送。

理由：
1. **文字零错字**：营销短信/海报中的小区名与联系方式错一字即事故，生成式中文渲染不可控。
2. **成本可控**：模板套版边际成本接近零；生成式按 0.2 元/张，日发 5000 张约 1000 元/天 ≈ 3 万元/月。
3. **性能与资源**：Sharp/libvips 约 20–200 ms/张、约 15 MB/请求，显著优于无头浏览器（300–600 ms、200–400 MB/实例、冷启动 1–3 s）。
4. **业务可控**：模板即品牌规范，运营可自行配置与预览，不依赖模型出图稳定性。

**生成式出图定位为可选增强**：允许运营用通义万相（如 wan2.2-t2i-plus / wan2.6-image，约 0.2 元/张）批量生成**背景图素材池**，人工审核后入库作为模板背景，**不在跑批链路内**。这样既保留了「个性化视觉」的想象空间，又不把不可控与高成本引入主链路。

## Consequences

### 对用户原始需求的重要说明（请用户知悉）

用户原始需求是「生产**个性化**的 AI 海报」。本决策**没有取消个性化，但把「个性化」的实现方式从「用 AI 模型逐张现画」改成「用模板 + 变量逐张组装」**——这是一次**实质性的实现路径变更**，必须先讲清楚，不默默改。

**为什么这么选，四句话**

1. **可控性**：海报上要印小区名、主推产品、联系方式，错一个字就是事故；模板的字是"打上去"的，绝不会写错，AI 生成的字经常糊、缺笔画、写错。
2. **成本**：模板套版几乎不花额外的钱（用的是我们自己的服务器）；AI 出图按张收费（约 0.2 元/张），发得越多花得越多。
3. **时延**：模板套版一张约 20–200 毫秒，几分钟内能出完当天全部海报；AI 出图一张要数秒，赶不上"每天一次"的节奏。
4. **可回归**：模板出图结果稳定，同样输入永远出同一张图，方便抽查与验收；AI 出图每次都不一样，出了问题无法复现。

**「个性化」体现在哪里（没有丢）**
个性化体现在**内容**：每个房屋拿到的海报，是根据它自己的标签（家庭结构、装修年限、渗漏情况）套进不同的模板与文案，产品名、卖点、称呼、小区名都是这一户专属的。视觉风格则通过**多套模板**来区分（不同产品包/不同人群用不同模板）。

**「生成式出图」作为可选增强的启用条件（满足其一即可启用）**

- 运营需要**批量补充背景图素材**，且愿意**人工审核后入库**再用于模板（即：AI 只画"底图"，文字仍由系统印）；
- 单批**实验量小**（例如 ≤ 200 张）时，允许用生成式做视觉 A/B 测试，且已设好**成本上限与人工复核**；
- 已确认品牌方接受"AI 生成背景 + 系统印字"的组合视觉规范。

不满足上述条件时，默认**不开启**生成式，跑批链路里不出现任何 AI 出图调用。

**如果用户坚持「全部用 AI 逐张生成」，代价如下（据此决策前请先算账）**

| 项目 | 代价 |
|------|------|
| 单张成本 | 约 0.2 元/张（通义万相 wan2.2-t2i-plus / wan2.6-image 公开价） |
| 典型日发送量（约 5000 张） | 约 1000 元/天，约 **3 万元/月** |
| 全量 125.7 万张（若要对全部房屋出图） | 约 **25 万元/次** |
| 批量时延 | 以通义万相 RPM 120 计，5000 张约 **42 分钟**；125.7 万张约 **7 天**（单批不可能当日完成） |
| 质量与品牌风险 | 中文文字易错字/糊字；构图不可控，可能生成不合规或不符合品牌的画面；每次结果不同，无法复现验收 |
| 合规风险 | AI 生成画面可能含商标、人物肖像等权利问题，营销物料需额外审核 |

结论：**逐张全生成式在当前成本、时延与品牌可控性下不可行**，故本决策采用模板套版为主、生成式降为可选增强。

### 常规影响

正面：
- 成本、可控性、性能最优；符合用户「业务可控性与成本优先」的倾向。
- 海报结果可复现、可回归测试。

负面：
- 视觉多样性弱于生成式，需设计方提供**多套模板**承担风格差异。
- 需要业务方/设计方提供背景素材与品牌字体（已在 OPEN-DECISIONS 登记为待确认项）。
