# ADR-004: 全项目锁定 Lucide 作为唯一 SVG 图标库

## Status

Accepted (2026-09-18)

## Background

团队级 P0 绝对规则：**禁止 emoji 作为功能图标**，Spec 必须锁定**同一套** SVG 图标库，前端依赖随之锁定，全项目不得混用。

候选：

| 候选 | 版本 | 图标数 | 描边可调 | Tree-shaking | React 支持 |
|------|------|--------|----------|--------------|-----------|
| Lucide | lucide-react ^1.44.0 | 1500+ | 支持（strokeWidth） | 支持（命名导出） | 官方一等公民 |
| Tabler Icons | @tabler/icons-react ^3.x | 5900+ | 支持 | 支持 | 官方 |
| Heroicons | @heroicons/react ^2.x | 292 | 不支持 | 支持 | 官方 |
| Phosphor | @phosphor-icons/react ^2.x | 7700+（6 字重） | 字重切换 | 支持 | 官方 |

## Decision

**锁定 Lucide**（React 包 `lucide-react@^1.44.0`；若前端改用 Vue 则对应 `lucide-vue-next@^1.x`，本 ADR 随前端栈更新）。

理由：
1. 24x24 统一栅格、`stroke-width` 可调（本设计需要 16/20/24px 三档，描边一致性关键），风格中性适合企业后台。
2. 图标数量满足营销后台全部语义（规则、推送、频控、名单、海报、审计等），无需引入第二套。
3. 官方 React 支持、命名导出可 tree-shaking，避免包体膨胀。
4. 备选：Tabler（图标更多）、Heroicons（Tailwind 生态）、Phosphor（多变体）。若未来确需扩展，须走 ADR 变更流程，禁止局部替换。

## 规范（强制）

| 项 | 约定 |
|----|------|
| 安装 | `npm install lucide-react@^1.44.0` |
| 栅格 | 24x24 viewBox，`fill=none`，`stroke=currentColor`，默认 `stroke-width=2` |
| 尺寸 | 仅 **16 / 20 / 24px** 三档（`--icon-sm/md/lg`），不得自造尺寸 |
| 颜色 | 一律 `currentColor`，禁止在图标上写死颜色 |
| 引入 | 必须命名导入 `import { Bell } from 'lucide-react'`，禁止整包/动态全量导入 |
| 禁止 | 禁止 emoji 替代图标；禁止多图标库混用；图标不得放大超过 24px 当插画用 |
| 无障碍 | 装饰性图标 `aria-hidden="true"`；语义性图标必须 `aria-label` |

## Consequences

正面：
- 全项目图标风格一致，符合 P0；尺寸/颜色受控。
- Tree-shaking 友好，包体可控。

负面：
- 团队不得从其它库复制 SVG（包括 Heroicons 风格的图标）。
- 若某个业务语义图标 Lucide 缺失，需按 Lucide 规范自建（`createLucideIcon`）而非引入新库。
